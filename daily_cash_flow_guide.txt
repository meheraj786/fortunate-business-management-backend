Here is a complete guide on how to use the Daily Cash Flow module via the API.

---
### **Daily Cash Flow Module Guide**
---

This module is designed to track the daily flow of cash (income and expenses) for the business.

### **Workflow Overview:**
1.  **Start the Day**: Open the cash for the current day. The opening balance is automatically carried over from the previous day's closing balance.
2.  **View Daily Status**: Fetch the day's cash summary, including opening balance, total income/expenses, and the list of transactions.
3.  **Record Transactions**:
    *   Cash payments from sales are **automatically** added as income.
    *   Manually add any other income or expenses that occur during the day.
4.  **End the Day**: Close the day's cash. No more transactions can be added after this.

---
### **1. Starting the Day (Opening Cash)**
---

This endpoint creates the cash entry for a specific day. The opening balance is now **100% automatic**.

*   **Endpoint**: `POST /api/cash/open`
*   **Description**: Initializes the cash for a given day. It automatically finds the previous day's closing balance and uses it as the new opening balance. If no previous day exists, the balance starts at 0.
*   **Request Body**:
    *   You can send an empty body `{}` to open the cash for **today's date**.
    *   Optionally, you can specify a date to open.

    ```json
    // To open for a specific date (e.g., if you missed a day)
    {
      "date": "2025-11-10T00:00:00.000Z"
    }
    ```

*   **Success Response (201 Created)**:
    *   Returns the newly created daily cash object, with the `openingBalance` and `runningBalance` correctly set.

---
### **2. Getting Daily Cash Information**
---

This is the main endpoint you will use to display the daily cash flow page.

*   **Endpoint**: `GET /api/cash/get-cash`
*   **Description**: Fetches all information for a specific day, including summary stats and a unified list of all transactions.
*   **Query Parameters**:
    *   `?date=YYYY-MM-DD`: To get the cash details for a specific date. If omitted, it defaults to **today's date**.
    *   Example: `/api/cash/get-cash?date=2025-11-10`

*   **Success Response (200 OK)**:
    *   Returns a single object containing the day's summary and a sorted list of transactions.

    ```json
    {
      "status": "success",
      "data": {
        "_id": "691a...",
        "date": "2025-11-10T00:00:00.000Z",
        "openingBalance": 165000,

        "runningBalance": 230000,
        "isClosed": false,
        "transactions": [

            "type": "income",
            "category": "Sale",
            "description": "Payment for new sale to John Doe",
            "amount": 50000,
            "paymentMethod": "cash",
            "sales": "691c...",
            "time": "2:30:15 PM"
          },
          {
            "_id": "691d...",
            "type": "expense",

    ```

---
### **3. Recording Transactions**
---

#### **a) Automatic Income from Sales**

*   **No API call needed from you!**
*   When you use the `POST /api/sales/create-sales` or `POST /api/sales/:id/payments` endpoints, if any payment in the `payments` array has `"method": "cash"`, it will be **automatically added** to the `incomeList` for that day.

#### **b) Manual Income**

*   **Endpoint**: `POST /api/cash/income`
*   **Description**: Use this to record any cash income that is **not** from a sale (e.g., receiving a refund, a loan, etc.).
*   **Request Body**:

    ```json
    {
      "date": "2025-11-10", // Optional, defaults to today
      "amount": 5000,
      "category": "Miscellaneous",
      "description": "Received refund from supplier"
    }
    ```

#### **c) Manual Expense**

*   **Endpoint**: `POST /api/cash/expense`
*   **Description**: Use this to record any cash expense.
*   **Request Body**:

    ```json
    {
      "date": "2025-11-10", // Optional, defaults to today
      "amount": 1500,
      "category": "Transportation",
      "description": "Delivery charge for order #123"
    }
    ```

---
### **4. Ending the Day (Closing Cash)**
---

This endpoint closes the cash for the day. Once closed, no more transactions can be added.

*   **Endpoint**: `POST /api/cash/close`
*   **Description**: Marks the daily cash record as closed.
*   **Request Body**:
    *   You can send an empty body `{}` to close for **today's date**.
    *   Optionally, you can specify a date.

    ```json
    {
      "date": "2025-11-10"
    }
    ```
*   **Success Response (200 OK)**:
    *   Returns the updated daily cash object with `isClosed` set to `true`.
